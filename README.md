# Global Natural Disasters Impacts Explorer

An interactive dashboard for exploring global natural disasters from 1900–2024.  
Built with Dash, Plotly, and Bootstrap.

## Overview
This dashboard allows users to visualize and analyze patterns in natural disasters worldwide. Users can filter by disaster type, year range, and impact metrics to explore global trends, regional distributions, and temporal variations.

## Features
- Interactive global map with disaster data by country and type  
- Time series and regional comparison plots  
- Seasonal and impact-based visualizations  
- Data smoothing using Gaussian filters

## Data
Data is sourced from the EM-DAT International Disaster Database.

## Installation and Usage

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/natural-disasters-dashboard.git
   cd natural-disasters-dashboard
   ```
2. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```
3. **Run the Dashboard**
   ```bash
   python Dash_App_Final.py
   ```
4. **View the App**
   ```bash
   open browser and go to http://127.0.0.1:8051
   ```
